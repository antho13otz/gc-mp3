# GC Station PC (Windows) — historique

Programme à part (`pc/`, sa propre copie du code), compilé par « GC Station PC (Windows) » (`windows.yml`). Les
numéros sont ceux de ces compilations (« build PC »). Privé : jamais publié, seulement joint aux compilations.

## PC 2 (build PC 46) — fichiers déposés, icône, dossier de réglages
- Fichiers déposés sur la fenêtre : copiés dans la carte (musique, photos, jeux, vidéos), liste relue.
- Icône près de l'horloge : clic = la fenêtre ; clic droit : « Démarrer avec Windows », Quitter.
- Dossier du programme protégé : carte et réglages dans `%APPDATA%\GC Station` ; sinon version portable.
- Réglages de la console retirés (réseau, mises à jour de la console, Pulse, langue / son / horloge de la console).

## PC 1 (build PC 41) — séparé de la console
- Sa propre copie du code (faite depuis la console v357), sa plateforme, ses essais, son Makefile, son README (`pc/README.md`).
- Un changement du PC ne fait plus de version de la console.

## Build PC 38 — souris, clavier qui tape, autres manettes, écrans
- Souris : la flèche suit, clic gauche = A, clic droit = B, molette.
- Le clavier du PC tape dans le clavier de GC Station et celui des pages web (accents compris) ; Ctrl+F : recherche / adresse ; Espace : lecture / pause ; touches multimédia.
- Manettes PlayStation et génériques (`manette.txt`) ; net sur les écrans à 125 / 150 % ; Maj+F11 : écran suivant (`fenetre.txt`).

## Build PC 24 — la mise à jour remplace vraiment le programme
- La nouvelle version prend la place du programme en marche, puis l'ancienne est effacée au démarrage suivant.
