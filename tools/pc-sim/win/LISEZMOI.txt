GC STATION PC (Windows)
=======================

GC Station, comme sur la GameCube, dans une fenetre de Windows : musique, radio, photos,
Salon (avec les autres GC Station), et tes jeux GameCube lances dans Dolphin.

1) Demarrer
   Dezippe tout le dossier ou tu veux, puis lance « GC Station.exe ».
   Le dossier « sd » a cote du programme est sa carte SD : mets-y ta musique (dossier mp3),
   tes photos, et tes jeux GameCube (.iso, .gcm, .ciso), comme sur la carte de la console.
   Windows peut demander d'autoriser le reseau (pare-feu) : accepte, sinon le Salon ne marche pas.

2) Touches
   Fleches        croix                 Entree / Espace   A
   Retour arriere B                     Echap / F1        START (menu)
   Tab ou Z       Z (onglet suivant)    X, Y              X, Y
   Page prec./L   L                     Page suiv./R      R
   F11 (ou Alt+Entree) : plein ecran.          F9 : chercher une mise a jour.
   Une manette Xbox (ou compatible XInput) marche aussi : A B X Y, Start = START, Back = Z,
   LB / RB = L / R, sticks.

3) Les jeux : avec Dolphin
   Installe Dolphin (https://dolphin-emu.org), ou mets son dossier a cote de GC Station
   (un dossier « Dolphin » contenant Dolphin.exe), ou ecris le chemin de Dolphin.exe dans un
   fichier « dolphin.txt » a cote de GC Station. Choisir un jeu dans JEUX le lance dans Dolphin.

4) Salon par Internet (avec une GC Station chez quelqu'un d'autre)
   START > Reglages > Salon et telephone :
     - Salon : Oui
     - Salon par Internet : adresse de l'ami : son adresse Internet (IP, ou un nom comme
       ami.duckdns.org). Il suffit qu'un des deux la mette.
     - Salon par Internet : code : le MEME code chez les deux (au moins 6 caracteres).
   Celui qui heberge (celui dont l'adresse est donnee) ouvre dans sa box :
     - le port 51234 en UDP (le Salon) et 51238 en TCP (sa carte SD) ;
     - le port 51240 en UDP pour jouer en reseau local par Internet (ci-dessous).
   L'autre GC Station apparait alors dans FICHIERS, comme si elle etait chez toi.

5) Jeu en reseau local par Internet (deux GC Station PC)
   Avec le Salon par Internet regle (code commun), un jeu lance depuis GC Station PC a son
   adaptateur reseau relie a l'autre GC Station PC : Mario Kart Double Dash, Kirby Air Ride...
   en mode « LAN », comme si les deux PC etaient cote a cote. Il faut un ping faible (meme pays).
   (Le meme format que tools/lan-relais.py : une vraie GameCube avec un PC pont peut rejoindre.)

6) Mises a jour
   GC Station PC n'est pas public : il se met a jour depuis GitHub avec un jeton, comme l'appli
   du telephone. Cree un « fine-grained token » sur GitHub (Settings > Developer settings >
   Personal access tokens > Fine-grained tokens) : depot antho13otz/gc-mp3 seulement,
   permission « Actions : Read-only ». Colle-le seul dans un fichier « jeton-github.txt » a cote
   de GC Station.exe. Au demarrage, GC Station PC propose la nouvelle version s'il y en a une ;
   F9 : chercher maintenant. (L'ancienne version reste en « GC Station.exe.ancien ».)
   Ne donne pas ce jeton : il ouvre les compilations du depot.

Le journal est dans journal.txt (a cote du programme), en cas de souci.
